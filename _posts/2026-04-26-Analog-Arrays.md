#### Analog Arrays!
In this assignment, I was tasked to code a program that would use an array to store the values of multiple pins and the statuses of those pins to randomly turn a pin on and off. One tip that I would give to my past self completing this assignment is to start it earlier as I had to ask for an extension on this assignment and when time came to work on it I had forgotten how arrays worked.
